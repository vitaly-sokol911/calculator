# Калькулятор

Калькулятор для компьютера и телефона. Работает без интернета, ставится на домашний экран,
есть тёмная и светлая тема, ввод с клавиатуры, вибрация на телефоне.

**Открыть:** https://vitaly-sokol911.github.io/calculator/

- Один HTML-файл без библиотек и без сетевых запросов.
- Строгая политика безопасности (CSP): сторонние скрипты и сеть запрещены.
- Контраст текста не ниже 4,5:1 (WCAG AA), управление с клавиатуры.
- Интерфейс, иконки и персонажи нарисованы с нуля.
